# K-공포지수 — 권장 비중(사이징) 검증 명세

> 화면의 **"권장 비중 N%"**가 어떻게 나오는지 코드와 1:1 대조. 두 축(등급·depth)을
> 곱하고 코스닥 단독이면 상한을 씌운다. 계산 함수 = `src/client/pages/kfear.ts`의
> `computeSizing()`. 검증 테스트 = `scripts/parity/` 계열 유닛테스트(하단 참조).

---

## 1. 공식 (코드 그대로)

```ts
// kfear.ts
export const GRADE_COEF = { STRONG: 1.0, BUY: 0.75, ARMED: 0.65, WATCH: 0.45, IDLE: 0 };
export const KOSDAQ_ONLY_CAP = 30;

function depthBasePct(creditDd):            // 신용 낙폭(DD) → 기준 비중 %
  dd ≤ −0.25 → 100 · dd ≤ −0.15 → 70 · dd ≤ −0.08 → 40 · else → 20

computeSizing(grade, creditDd, regime):
  base = depthBasePct(creditDd)
  coef = GRADE_COEF[grade]
  pct  = round(base × coef)                 // Math.round = 반올림(.5는 올림)
  if regime == "KOSDAQ_ONLY" and pct > 30:  // 코스닥 단독만
      pct = 30 (capped)
  return { pct, base, coef, capped }
```

- **등급**(STRONG/BUY/ARMED/WATCH/IDLE) = FEAR≥90 + 신호 충족 수로 결정(별도 로직 `phase()`).
- **depth**(base%) = 신용 낙폭만.
- **동반**: 코스피는 상한 없음. 코스닥은 코스피 미동반(`KOSDAQ_ONLY`)일 때만 30% 상한.
- `round`는 JS `Math.round`(가장 가까운 정수, 0.5는 위로): 52.5→53, 45.5→46, 31.5→32.

---

## 2. 계수 근거 (백테스트 2020~ 통합, n=10~31)

| 등급 | n | 6달 평균 | 계수 |
|---|---|---|---|
| STRONG (FEAR90 & 3신호) | 10 | +20.3% | **1.0** |
| BUY (FEAR90 & 2신호) | 19 | +16.7% | **0.75** |
| ARMED (FEAR90 & ≤1신호) | 17 | +13.5% | **0.65** |
| WATCH (2신호 & FEAR<90) | 31 | +11.5% | **0.45** |
| IDLE | — | — | **0** |

동반: SYSTEMIC(코스피 동반) 6달 +25%·승률 80% → 상한 없음 / KOSDAQ_ONLY 6달 +0.5%·승률 50%(n=5) → **30% 상한**.

⚠️ **방향성(STRONG>BUY>ARMED>WATCH)만 신뢰구간**. 계수 소수점은 노이즈 — 어느 등급이든 6달 +11~20%(전부 플러스). "STRONG 풀·WATCH 절반" 수준의 차등일 뿐, 0.05 차이로 승부 안 갈림.

## 3. 검증 진리표 (코드 실행값과 대조)

`pct = round(base × coef)`. 코스피(동반 상한 없음) 기준:

| 등급 (coef) | DD −30%·base100 | −20%·base70 | −10%·base40 | −5%·base20 |
|---|---|---|---|---|
| STRONG (1.0) | **100** | **70** | **40** | **20** |
| BUY (0.75) | **75** | 52.5→**53** | **30** | **15** |
| ARMED (0.65) | **65** | 45.5→**46** | **26** | **13** |
| WATCH (0.45) | **45** | 31.5→**32** | **18** | **9** |
| IDLE (0) | 0 | 0 | 0 | 0 |

### 코스닥 단독(KOSDAQ_ONLY) — `min(pct, 30)`

| 케이스 | base × coef | 상한 전 | **최종** | capped |
|---|---|---|---|---|
| STRONG · DD −30% | 100 × 1.0 | 100 | **30** | ✅ |
| STRONG · DD −20% | 70 × 1.0 | 70 | **30** | ✅ |
| BUY · DD −20% | 70 × 0.75 | 53 | **30** | ✅ |
| BUY · DD −10% | 40 × 0.75 | 30 | **30** | ✗ (30은 초과 아님) |
| BUY · DD −5% | 20 × 0.75 | 15 | **15** | ✗ (<30) |
| ARMED · DD −10% | 40 × 0.65 | 26 | **26** | ✗ |

### 사용자 워크드 예시 (오늘 화면)

| 시장 | 등급 | DD | 동반 | 계산 | **권장 비중** |
|---|---|---|---|---|---|
| 코스피 | BUY | −2.3% | (상한없음) | 20 × 0.75 | **15%** |
| 코스닥 | STRONG | −27.7% | SYSTEMIC | 100 × 1.0 | **100%** |
| 코스닥(가정) | STRONG | −27.7% | KOSDAQ_ONLY | 100 × 1.0 → 상한 | **30%** |

### 경계값

| creditDd | base% | 이유 |
|---|---|---|
| −0.25 (정확) | 100 | `dd ≤ −0.25` 포함 |
| −0.2499 | 70 | −0.25 미달 → 다음 구간 |
| −0.15 (정확) | 70 | `dd ≤ −0.15` |
| −0.08 (정확) | 40 | `dd ≤ −0.08` |
| −0.079 | 20 | −0.08 미달 |
| null (신용 없음) | 20 | 기본 소액 |

## 4. 직접 검증 방법

1. **유닛테스트**: 위 진리표는 `computeSizing` 유닛테스트로 검증됨(코스피 BUY→15, 코스닥 STRONG SYSTEMIC→100, 단독→30, BUY 단독 −20%→30, ARMED −10%→26, WATCH −16%→32, IDLE→0, depth 경계 전부).
2. **코드 대조**: `kfear.ts`의 `GRADE_COEF`·`KOSDAQ_ONLY_CAP`·`depthBasePct`·`computeSizing`이 위 §1과 일치하는지.
3. **화면 대조**: 카드의 `권장 비중 N%` + `depth B% × 등급 G C` 분해가 진리표와 맞는지. 코스닥 단독이면 `→ 코스닥 단독 30% 상한` 표기.

> ⚠️ 이 계수·상한은 소표본 백테스트 기반의 **참고 가이드이며 투자 권유가 아니다.** 방향성은
> 신뢰하되 정밀 수치는 노이즈로 간주. 모든 판단과 결과는 사용자 책임.

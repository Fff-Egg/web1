# 지표 1 — K-공포지수 (국내: 코스피·코스닥 캐피출레이션 바닥)

**파일**: `src/client/pages/kfear.ts`(계산) · `KFearPanel.tsx`(UI) · 데이터 `src/server/market/{koreaIndexes,credit,forcedLiq,anchors}.ts`

## 1-A. 개요
코스피·코스닥 **각각**에 대해 신용잔고·반대매매·이격도·실현변동성을 **252일 롤링 분위수**로 정규화해 0~100 공포지수(FEAR)를 만들고, 투매 청산 바닥을 포착하는 3신호(S1/S2/S3)를 켠다. `FEAR≥90` 여부 + 신호 개수로 등급(STRONG~IDLE)을 매기고, `등급 기본비중 × 이중 얕음게이트 × 코스닥 단독 규칙`으로 권장 진입 비중(%)을 낸다. **절대값이 아니라 롤링 분위수를 쓰는 게 핵심** — 레짐 변화(금리·유동성)를 흡수한다.

## 1-B. 상수 (코드 실제값)
```
PCT_WIN=252 · SPIKE_PCT=0.95 · SPIKE_LOOKBACK=6
CREDIT_DD=-0.08 · CREDIT_10D=-0.03 · PEAK_MINP=200
DISP_N=60 · DISP_ABS=92.0 · DISP_PCT=0.05 · RV_N=20 · FEAR_ARM=90
GRADE_WEIGHT={STRONG:100, BUY:60, ARMED:50, WATCH:45, IDLE:0}
KOSDAQ_SOLO_CAP=0 · SHALLOW_CREDIT=-8 · SHALLOW_DISP=-7
# DD2=-0.15, DD3=-0.25 는 phase()의 레거시 size 문자열용(사이징 아님, UI 미표시)
```
`rollPct(arr, 252)`: `out[i] = (창내 v≤cur 개수)/252`, 단 최근 252개(자기 포함)가 **전부 유한**할 때만(아니면 NaN). pandas `(w<=w[-1]).mean()` 이식.

## 1-C. FEAR = 4성분 동일가중 skipna 평균 ×100
```
F1 = 1 − pct252(신용융자 10일 변화율)      # 청산 '속도'  (credit10d = creditA[i]/creditA[i-10]−1)
F2 = pct252(반대매매 금액)                 # 강제청산 강도 (v4~ 절대금액, 비중 아님)
F3 = 1 − pct252(60일 이격도)               # 가격 낙폭    (disp = close/ma60×100)
F4 = pct252(20일 실현변동성)               # 패닉(VKOSPI 대용, rv = std(logret,20)×√252×100)
FEAR = mean_skipna(F1,F2,F3,F4) × 100      # 전부 NaN이면 NaN
```
- `1−pct` 반전(F1·F3): 신용 변화율·이격도는 **낮을수록** 공포라 반전. F2·F4는 높을수록 공포라 그대로.
- **F1 vs S1**: 같은 신용을 F1은 *속도*(10일 변화율), S1은 *깊이*(252일 피크대비 누적 낙폭)로 본다 — 다른 측면.

## 1-D. 3신호 (ON/OFF)
```
S1 신용청산 = creditDd ≤ −8% AND 신용 10일변화 ≤ −3% AND 지수 10일수익률 < 0
              creditDd = creditA/peak − 1, peak = rollMax(creditA, 252, minP=200)

S2 반대매매 (v5 복원) = spike6 AND decline2
   spike[j]   = 반대매매 금액 분위 amtPct[j] ≥ 0.95        (상위5% 스파이크 당일)
   spike6[i]  = 최근 6거래일(i−5..i) 중 spike 존재
   decline2[i]= amtA[i] < amtA[i−1] AND amtA[i−1] < amtA[i−2]   (2일 연속 '엄격' 하락, 동률·ffill 제외)
   → 청산 파도가 정점 찍고 잦아드는 것(통상 정점+2일) 확인 후 점등.
     스파이크 당일은 오르는 중이라 OFF, 재급증(2차 파도) 시 decline2 깨져 OFF.

S3 이격도60 = disp ≤ 92  (60일선 대비 −8%)  OR  dispPct ≤ 0.05  (1년 하위5%)
```
**신호 강도 배지(표시용, level 0~3 = 관망/경계/공포/심각)**: S1 = creditDd별, S2 = amtPct별(≥0.99 심각/≥0.95 공포/≥0.9 경계), S3 = disp·dispPct별.

## 1-E. 등급 & 권장 비중
```
phase(FEAR, nOn):
  FEAR≥90 & 3신호 → STRONG(최강 매수국면)
  FEAR≥90 & 2신호 → BUY(매수국면)
  FEAR≥90 & ≤1신호 → ARMED(경계)
  FEAR<90 & 2신호↑ → WATCH(관찰)
  else → IDLE(평시)

computeSizing(grade, creditDd, dispDev, isSolo):   # 우선순위 ①→② 엄수
  ① isSolo(코스닥 단독) → 0%, path=SOLO            # 등급 무관 최우선
  ② weight = GRADE_WEIGHT[grade]; weight==0 → 0%, path=NONE
     gate = shallowGate(creditDd, dispDev)
     pct  = round(weight × gate), path = gate<1 ? GATED : FULL

shallowGate: 신용DD*100 > −8  AND  이격도편차 > −7  (둘 다 얕음) → ×0.5, 아니면 ×1.0
             null 값은 '얕음'으로 취급. STRONG도 게이트 적용.
```
**코스피 동반**: `kospiAccompanies = 코스피 FEAR≥90`. 코스닥 regime = 동반이면 SYSTEMIC(✓동반 배지), 아니면 KOSDAQ_ONLY(→ isSolo=true → 0%, '관찰 — 코스피 동반 대기'). 코스피는 항상 isSolo=false(기준 시장).

## 1-F. 차트 & UI (카드당 4개)
① FEAR 추이(임계 90) ② S1 신용 DD %(−8·−15) ③ **S2 반대매매 금액 1년 분위(95=상위5%) + 계단식 Stage1/첫감소/Stage2 + 공식 S2 구분 마커** ④ S3 이격도 편차 %(−8). 전부 완전워밍업(~311거래일) 이후만.
- **공식과 실험 분리**: 공식 v5 S2·STRONG·권장비중은 그대로다. 별도 `staged execution`은 Stage 1 60% 후 같은 에피소드의 2일 엄격 감소에 Stage 2 +40%를 표시한다. 목표 0%는 매도 지시가 아니다.
- **미국 확인**: Tier0·1·2 타임라인은 경고/확인 정보만 제공하고 60/100을 자동 변경하지 않는다. 라이브는 기준일 이후 데이터를 자르며, ±21일은 과거 백테스트 분류에만 쓴다.
- **장기 백테스트**: A~E 비교, 일별 계단식 에쿼티/MDD, 다음 거래일 시가, paired/2020제외/미국분리는 `docs/kfear-staged-backtest.md` 참고.
- FEAR 게이지 90 임계선. 신용 히스토리 부족 시 S1을 '⚠️ 비활성'으로 명시(커버리지 가드, PEAK_MINP<200).

## 1-G. 데이터 · 정렬 (함정 주의)
- **소스**: 지수종가=TradingView `KRX:KOSPI/KOSDAQ`(1200일) · 신용융자=KOFIA FreeSIS(5년) · 반대매매=KOFIA 증시자금(비중%+절대금액 1200일).
- **KST 거래일 키** `kstDay(t)=floor((t+9h)/DAY)`: 소스마다 타임스탬프 규약이 달라도 같은 거래일이면 같은 키 → `alignFfill`이 결정적.
- **⚠️ KOFIA T+1 정렬**: 지수는 당일, KOFIA는 T+1이라 평가 기준일을 **KOFIA 최신 거래일로 truncate**(`lastKofiaKey`). 안 하면 지수-앞선 하루가 ffill로 flat이 돼 F1/F2/S1·금액 분위가 왜곡. 그래서 **기준일이 어제로 뜰 수 있음(정상)**.
- **⚠️ KOFIA ÷8 단위 함정**: 게이트웨이가 잔고·금액을 실제 원의 1/8로 반환 → 신용은 `×8` 보정(`credit.ts` KOFIA_UNIT_FACTOR=8). 반대매매 금액도 ÷8이나 pct252는 스케일 무관이라 raw 저장.
- **반대매매 금액 컬럼 식별**: `forcedLiq.ts`가 이중 2점 앵커(07-09/07-07≈4.48 AND 07-10/07-08≈2.83, 완전 스케일무관)로 컬럼 특정, 미식별 시 비중으로 폴백('⚠비중 폴백' 표기).

## 1-H. 설계 근거 (왜 이렇게 됐나 — 되돌리지 말 것)
- **절대금액 vs 비중(F2·S2)**: 비중(반대매매÷미수금)은 분모(미수금)가 반대매매와 연동돼 왜곡(2023-10 뻥튀기 69%, 2025-04 희석 1.8%). → **절대금액**만 사용. 구조적 근거.
- **depth 4단 사다리 폐지**: 과거 신용DD 깊이로 4단 사이징하던 것 폐지 — FEAR≥90 시점엔 신용이 이미 깊어 무의미(병합 20건 중 18건이 이미 DD≤−8%). 신호개수→등급→GRADE_WEIGHT로 직결.
- **이중 얕음게이트**: 신용DD·이격도편차 상관 −0.04(독립). '둘 다 얕음' +5.6% vs '하나만 얕음' **+23.8%**(오히려 최고 → 안 깎음). 둘 다 얕을 때만 가짜바닥으로 ×0.5.
- **S2 v5 복원**: v4에서 '스파이크 당일 단일조건'으로 단순화했으나 그 근거 테스트가 오류였음이 확인돼 원설계('스파이크 6일내 & 2일 연속↓')로 복원. 채택 근거 = **MDD 7/8 개선 + STRONG 진입가 −2.4~3.9% 우위**(더 싸게 진입). 비용 = 빠른 V반등 2일 지각. **수익 우열은 소표본 노이즈로 미증명** — MDD·진입가로만 채택.
- **코스닥 단독=0%**: 코스닥 단독 6달 +0.5%·승률 50%·n=5 = 기대값 0. 코스피 동반 시 자동 승격.
- **코스피 동반 = FEAR≥90 단독**: 과거 OR로 봤던 ALL3·DD≤−15%는 표본에서 FEAR 위로 기여 0.
- **F4 = VKOSPI 대용**: 못 가져오던 VKOSPI 대신 20일 실현변동성 분위로 대체.

## 1-I. 검증 & 한계
- **유닛테스트**: T1~T12(사이징, T5≠T6이 게이트 핵심) · S2-a~f(스파이크/2일↓/동률/6일창) · F2 금액·폴백. (scratchpad)
- **앵커**(HARD, 불일치 시 소스 거부): 신용 유가 07-07=29.075조·코스닥 7.990조·합(06-24)=38.633조, 반대매매 07-07=2.2%, 코스피 종가 06-23=8203.84·07-08=7246.79. 코스닥 종가는 소프트 드롭+sanity band(200~4000).
- **성과(소표본)**: 6달 가중 +16.3%(현행 +11.5%). STRONG 20.3 > BUY 16.7 > ARMED 13.5 > WATCH 11.5(단조감소) — **방향성만 신뢰**, 계수 소수점은 노이즈.
- **한계**: n=6~16(코스닥 단독 n=5). ~311거래일 완전 워밍업 이후만 신뢰. 파서 실검증은 Railway 필요(샌드박스 egress 차단).

## 1-J. ⭐ 조정 가능 vs 고정 (개선 시 필독)
- **고정(검증 상수, 임의 변경 금지)**: PCT_WIN=252 · SPIKE_PCT=0.95 · SPIKE_LOOKBACK=6 · CREDIT_DD=−0.08 · CREDIT_10D=−0.03 · DISP_N=60 · DISP_ABS=92 · DISP_PCT=0.05 · RV_N=20 · FEAR_ARM=90.

# 지표 2 — US 진입신호 실행기 (미국: 나스닥 진입 타이밍)

**파일**: `src/client/pages/usEntry.ts`(판정) · `USEntryPanel.tsx`(UI) · 데이터 `src/server/market/usEntry.ts`

## 2-A. 개요
나스닥 진입 타이밍을 **절대값 2트랙**으로 잰다. VIX 만기구조 역전(`TERM=VIX/VIX3M`)과 하이일드 신용스프레드(HY OAS)를 A/B 트랙으로 판정하고, 나스닥 낙폭 기반 **3단 티어(예비대→본대→최대)**로 진입 규모를 나눈다. 합성지수가 아니라 절대 임계값 + 상태머신 구조. 지시서 v1.0(7788조합 백테스트) 기반. n=10~13 소표본(2008급 미포함).

## 2-B. 상수 (코드 실제값)
```
TERM_A=1.05 · TERM_ARMED=1.00 · TERM_WATCH=0.95
HY_B=4.5 · HY_WATCH=4.25 · VIX_MEGA=40
MERGE_TD=21(에피소드 병합/POST창) · DD_TIER0=-0.08 · HIGH_WIN=252 · SMA_TREND=200
```

## 2-C. 신호 (2트랙)
```
TERM = VIX 종가 / VIX3M 종가   (같은 UTC 거래일)
A (주 진입) = TERM ≥ 1.05
B (강 신호) = TERM ≥ 1.00  AND  HY_shift ≥ 4.5%     # HY는 T+1 → D-1 관측치 사용
fired = A OR B      (A∪B=진입권, A&B=AB 최상급)
MEGA 배지 = VIX ≥ 40
```

## 2-D. 상태머신 & 레이어 (우선순위 ACTIVE > ARMED > WATCH > POST > IDLE)
```
fired[L]              → ACTIVE_AB(A&B) / ACTIVE_A / ACTIVE_B
else TERM ≥ 1.00      → ARMED
else TERM ≥ 0.95 or HY_shift ≥ 4.25 → WATCH
else L−lastFired ≤ 21 → POST     (소멸 후 21거래일 참고창)
else                 → IDLE
```
- **레이어1(신호 상태)**: `activeDays` = 오늘부터 뒤로 연속 fired 런. 쿨다운 없이 매일 재평가 → 첫날 놓쳐도 '연속 N일차'로 추격 진입 판단. `nasdaqSince` = 에피소드 첫 발동가 대비 현재 나스닥 등락률.
- **레이어2(에피소드)**: fired를 21거래일 병합(gap≤21 = 같은 에피소드). 통계·직전 발동 표시에만, 매수 억제엔 안 씀.

## 2-E. 3단 티어
```
tier = fired[L] ? ((A&B) || MEGA ? 2 : 1) : (tier0 ? 0 : null)

Tier 0 조정매수 = 나스닥 IXIC 고점(52주)대비 DD ≤ −8%  AND  200일선 위   → 소량(10~20%, 예비대)
   dd = close/rollMax(close,252) − 1,  above200 = close > rollMean(close,200)
Tier 1 주신호 = A or B                                                  → 본대
Tier 2 확인상향 = AB 동시 or MEGA(VIX≥40)                               → 최대
```
- **200일선 필터가 강세장 조정↔하락장을 가른다**: 강세장 조정은 −8%에도 200일선 위지만, 하락장은 −8% 시점에 이미 200일선 아래라 자동 off(자기 추세 대비 위치 = 자기정규화, TERM이 비율이라 살아난 것과 같은 계열).
- Tier0은 폭락/조정 사전 구분 불가(2020-02에도 켜져 1달 −17.6% 선제 피격→6달 +26.9% 회복) → **반드시 소량 전용**, 이후 A/B 뜨면 본대 들어가는 2단 구조.

## 2-F. 데이터 · 정렬
- **수집(`fetchCloses`, TradingView WS 미러, 5년/`HISTORY_DAYS`)**:

## 2-J. VVIX 단기 반등 확인 (보조 신호 — Tier와 완전 분리)

**파일**: `usEntry.ts`의 `computeVvixRebound`(기존 `computeUsEntry` **밖**의 독립 순수함수) · `USEntryPanel.tsx`의 `ReboundBlock` · 수집 `server/market/usEntry.ts`

### 목적
Tier 0·1·2가 **공포의 깊이와 진입 규모**를 재는 것과 달리, 이 신호는 **공포가 끝나기 시작했는지**만 본다.
포착 순서 = 옵션 변동성 공포 극단 → VIX 진정 시작 → 1주~1개월 단기 반등 확인.
> "얼마나 살 것인가"는 Tier가 정하고, "공포가 진정되기 시작했는가"는 이 신호가 보조한다.

### 정의
```
VVIX_PANIC=140 · VVIX_LOOKBACK_TD=3 · VVIX_LOOKBACK_CAL_DAYS=10 · VVIX_STALE_TD=3

panicRecent = 최근 3거래일(기준일 포함) 중 VVIX 종가 ≥ 140         # >= 엄격, 139.999는 false
cooling     = 오늘 VIX 종가 < 직전 거래일 VIX 종가                  # < 엄격, 동률은 진정 아님
CONFIRMED   = panicRecent AND cooling
PANIC       = panicRecent AND NOT cooling
IDLE        = NOT panicRecent
UNAVAILABLE = 행 2개 미만 | VVIX 시리즈 없음 | VVIX가 VIX보다 3거래일 초과 stale
```
**fired·tier·state·sizing·activeDays·POST·Tier0 앵커에 일절 들어가지 않는다.** 화면에서 `state=IDLE`과 `REBOUND CONFIRMED`가 동시에 뜨는 것이 정상이다.

### 데이터 · 정렬 (⚠️ 여기가 핵심)
- **수집**: `CBOE:VVIX` (폴백 bare `VVIX` → ws가 CBOE:VVIX로 자동 해석).
  ⚠️ **`TVC:VVIX`·`FRED:VVIXCLS`는 존재하지 않는 심볼**(실측 n=0) — 폴백에 넣지 말 것.
- **판정 행 배열 = `VVIX ∩ VIX` 를 UTC `dayKey` 정확 일치로 조인**(ffill 금지, VIX3M/TERM 타임라인과 **독립**).
  - 교집합인 이유(실측): `TVC:VIX`에는 5년간 **미국 휴장일 유령봉 22개**가 있고 값이 전일과 달라, raw VIX로 cooling을 재면 **증시가 닫힌 날 하락으로 잡힌다**. VVIX(CBOE)는 실거래일만 있어 교집합이 곧 실거래일 캘린더다(TERM 타임라인 1254/1254 = 100% 커버).
  - VIX3M과 분리한 이유: `computeUsEntry`는 VIX3M이 비면 계산 전에 `return EMPTY`한다. 안에 넣으면 VIX3M 하나가 죽을 때 VVIX 카드까지 죽어 "VVIX만 격리" 요구를 스스로 어긴다.
- **VVIX·VIX 모두 shift 없음**(HY만 기존 shift(1) 유지). 일봉 **종가**만, 장중 OHL 금지, 미래 데이터 금지.
- **데이터 구멍 방어**: lookback 창의 행이 기준일로부터 10달력일을 넘으면 '최근'으로 안 친다(수집 실패 시 `carryForwardEmpty`가 묵은 시리즈를 되살리므로 행 인덱스만으론 부족).
- **stale 방어**: VVIX 기준일이 VIX 최신일보다 3거래일 넘게 뒤처지면 UNAVAILABLE(옛 VVIX × 오늘 VIX 조합 차단).

### 한계 (UI에도 상시 표기)
- VVIX **절대 수준 140** 기반 소표본 관찰 신호. **2008년 금융위기를 포착하지 못했다.**
- 장기 추세 전환·독립 진입권을 의미하지 않는다. **3개월 이후는 약세장 중간 반등 실패**가 드러난다.
- 발동 빈도가 2007~2019 4건 → 2020~2026 10건으로 뛰었다 = VVIX 분포가 비정상(non-stationary)이라는 신호. 140은 "고정"이 아니라 **표본 내에서 선택된 값, 표본 외 검증 전까지 동결**로 취급한다.
- **채택 규칙 자체가 동일 탐색에서 선택돼 표본 내 성과가 상방 편향**돼 있다(§19가 제외한 'VVIX 자체 하락' 변형도 같은 탐색 산물).
- Tier 성과(6개월 지평)와 직접 비교 불가 — 지평·표본·기간이 다르다.

### ⭐ 조정 가능 vs 고정
- **고정**: `VVIX_PANIC=140` · `VVIX_LOOKBACK_TD=3` · VIX strict `<`(동률 불인정) · Tier 비침범 · UTC dayKey · 일봉 종가 · VVIX∩VIX 교집합 조인.
- **하지 말 것**: VVIX를 Tier 3으로 추가 · `fired`에 포함 · 자동 sizing 연결 · VIX 동률을 cooling 인정 · rolling percentile로 임의 변경 · 2008년까지 잡으려고 130으로 낮추기 · `TVC:VVIX` 폴백 부활(죽은 심볼) · `computeUsEntry` 안으로 이동.

# 공통 사항 & 개선 방향 힌트

- **두 지표의 대칭 구조**: K-Fear(kstDay) ↔ US(UTC dayKey), 둘 다 클라 순수함수(`__test`로 유닛테스트), 둘 다 소표본 면책.
- **데이터 정합성 방어**(`market/anchors.ts`): HARD assert(불일치→소스 거부) + SOFT 경고(→errors[] 화면 배너). 실측값 못박음. 소스가 조용히 틀어지는 것 차단.
- **개선 시 원칙**: 이 지표들은 검증된 백테스트 레퍼런스에서 왔다. 수치 미세조정보다 **① 표본 확장(과거 신호 성적표)** ② **표시 개선**(신호 점등 시점 가시화 — S2 마커처럼) ③ **알림/자동화**(상태전이 텔레그램) ④ **새 성분/신호 추가 후 백테스트** 방향이 안전. 상수 변경은 반드시 에쿼티 커브 재검증 동반.
- **미구현(공통)**: 다이제스트에 시황 한 줄, 상태전이 알림, 계단식 전략의 확정 보유·청산 규칙.

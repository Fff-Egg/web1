# K-공포지수 · 캐피출레이션 바닥 — 구현 명세 (검증용)

> 화면의 **"K-공포지수 · 캐피출레이션 바닥 / 코스피·코스닥 · FEAR(0~100)+3신호"** 패널이
> **어떤 데이터를 → 어떻게 계산해서 → 저 숫자로** 나오는지, 코드와 1:1로 대조 가능한 명세.
> 계산 로직은 검증된 레퍼런스(`capitulation_backtest.py` / `fear_index.py` / `fear_executor.py`)를
> TypeScript로 이식한 것이다.

## 1. 데이터 소스 (수집)

세 곳 전부 로그인 불필요. 지수는 당일, KOFIA 둘은 **T+1**(익일 공표).

### 1-1. 지수 종가 — `koreaIndexes.ts`
- 소스: TradingView 차트 WebSocket, 심볼 `KRX:KOSPI` / `KRX:KOSDAQ` (일별 종가, 1,200 거래일).
- 쓰임: S3 이격도, F3, F4(실현변동성), S1의 지수방향.

### 1-2. 신용거래융자 잔고 — `credit.ts`
- 소스: KOFIA FreeSIS `getMetaDataList.do`, 서비스 `STATSCU0100000070`, `OBJ_NM=STATSCU0100000070BO`.
- 컬럼: `TMPV3`=유가증권(코스피), `TMPV4`=코스닥. (`TMPV2`=전체, `TMPV5~7`=대주, `TMPV8`=청약, `TMPV9`=담보)
- **⚠️ ×8 단위 보정**: 게이트웨이가 잔고를 **실제의 정확히 1/8**로 반환한다(전 컬럼·전 날짜 일관).
  코드: `TO_JO = 1e12 / 8 = 1.25e11`, 값 = `TMPV / TO_JO` = (원값 × 8) ÷ 1e12 = **조원**.
  - 검산(2026-07-07): `TMPV3 = 3,634,371,585,697` → `/1.25e11 = 29.0750` → **29.075조** = KOFIA 실화면 유가 29,074,973 백만원. 정확 배수 8.000000, 그리고 `TMPV3+TMPV4 = TMPV2` 오차 0.

### 1-3. 반대매매 비중(%) — `forcedLiq.ts`
- 소스: KOFIA FreeSIS, 서비스 `STATSCU0100000060` (증시자금추이).
- 컬럼: `TMPV7` = 미수금 대비 반대매매 비중(%). **코스피·코스닥 공통값**(시장 구분 없음).
- 컬럼 식별: **앵커 고정** — 2026-07-07에 값이 `2.2`인 컬럼을 찾아 선택(컬럼 재정렬에도 견고). 앵커일이 창 밖이면 중앙값(전 TMPV* 스캔) 폴백.

## 2. 시간 정렬 — KST 거래일 (`kfear.ts`)

소스마다 타임스탬프 규약이 다르다(KOFIA=`Date.UTC` 자정, TV 일봉=UTC자정 or KST자정=전일 15:00Z). 그래서 **KST 거래일 정수 키**로 통일한다:

```
kstDay(t) = floor( (t + 9시간) / 86400000 )      // 같은 거래일 → 같은 키
```

- `alignFfill(지수날짜, KOFIA시리즈)`: KOFIA를 지수 거래일에 맞춰 **as-of ffill**(그 거래일 이하 최근값). `kstDay`로 비교하므로 TV 규약과 무관하게 결정적.
- **KOFIA T+1 truncate**: `lastKofia = min(신용 마지막 거래일, 반대매매 마지막 거래일)`. 지수를 그 거래일까지만 남긴다(`kstDay(지수) ≤ lastKofia`). 지수가 앞선 하루가 ffill로 신호를 흐리는 것 방지. → **기준일이 어제로 보일 수 있음(정상)**.

밀리던 지표는 KOFIA계열(S1/S2/F1/F2)뿐, 지수계열(S3/F3/F4)은 무관 — 이 정렬로 근본 제거.

## 3. 공통 엔진 — 252일 롤링 분위수 (`rollPct`)

절대 임계 대신 **분위수**로 정규화 → 레짐 변화 자동 흡수(예: 반대매매 비중이 2023년 전 5~7% → 지금 1~3%).

```
rollPct(값[], win=252):
  각 시점 i에서, 최근 win개(자기 포함, 전부 유한) 중 값[i] 이하인 날의 비율(0~1)
  = (#{ j ∈ [i-251, i] : 값[j] ≤ 값[i] }) / 252
  창에 NaN이 하나라도 있으면 NaN (min_periods=win)
```

예) 분위수 0.86 = 지난 1년의 86%보다 높음 = **상위 14%**. 화면의 "상위 X%·하위 X%·최저권"이 전부 여기서.

## 4. FEAR 지수 (0~100)

네 성분을 각각 분위수로 정규화 → **동일가중 평균 ×100**. 값이 높을수록 공포. (성분 하나가 NaN이면 나머지만 평균 = pandas `skipna`)

| 성분 | 공식 | 의미 |
|---|---|---|
| **F1** 청산속도 | `1 − rollPct( 신용 10일 변화율 )` | 신용이 빠르게 줄수록 공포↑ |
| **F2** 강제매물 | `rollPct( 반대매매 비중 )` | 반대매매 많을수록 공포↑ |
| **F3** 가격낙폭 | `1 − rollPct( 이격도 )` | 60일선 아래로 벌어질수록 공포↑ |
| **F4** 패닉강도 | `rollPct( 20일 실현변동성 )` | 흔들림 클수록 공포↑ (**VKOSPI 대용**) |

```
이격도(disp)   = 종가 / (60일 단순이평) × 100
실현변동성(rv) = std( ln(종가).diff(), 20, 표본ddof=1 ) × √252 × 100
FEAR = mean_skipna(F1, F2, F3, F4) × 100
```

- **F1 vs S1 차이**: F1은 신용의 *속도*(10일 변화율), S1은 *깊이*(피크 대비 누적 낙폭). 같은 재료의 다른 측면 — 상관은 있지만 일치하진 않음.
- **F4가 VKOSPI 대용** — 못 가져오는 VKOSPI 대신 지수 종가로 실현변동성 계산.

## 5. 3신호 (S1 / S2 / S3)

상수(레퍼런스 고정): `PCT_WIN=252, SPIKE_LOOKBACK=6, SPIKE_PCT=0.95, CREDIT_DD=-0.08, CREDIT_10D=-0.03, PEAK_MINP=200, DISP_N=60, DISP_ABS=92.0, DISP_PCT=0.05`.

### S1 신용청산 (AND — 독립 증거 3개)
```
peak      = rollMax(신용, 252, min_periods=200)
creditDd  = 신용 / peak − 1              // 1년 피크 대비 낙폭
credit10d = 신용 10일 변화율
idx10d    = 지수 10일 변화율
S1 = (creditDd ≤ −0.08) AND (credit10d ≤ −0.03) AND (idx10d < 0)
```
※ 최근 252창에 유한 신용값이 200 미만이면(부분수집) `peak=NaN` → S1이 조용히 항상 미충족이 되므로, 그 경우 **"신용 히스토리 부족"으로 명시**(커버리지 가드).

### S2 반대매매 (spike AND 꺾임)
```
spike = 최근 6거래일 중 rollPct(반대매매) ≥ 0.95 가 하나라도  (상위 5% 스파이크)
decl2 = 반대매매[오늘] < 반대매매[어제] < 반대매매[그제]        (2거래일 연속 하락)
S2 = spike AND decl2
```
※ 정렬은 과거→최신 오름차순 전제(`decl2`가 뒤집히지 않게). KST truncate 덕에 오늘=KOFIA 실제 최신일이라 ffill-flat로 안 깨짐.

### S3 이격도60 (OR — 같은 현상 두 잣대)
```
S3 = (이격도 ≤ 92)  OR  (rollPct(이격도) ≤ 0.05)     // 절대 or 1년 하위5%
```

### 집계
```
n_on = S1 + S2 + S3   (0~3),  ALL3 = n_on==3
```

## 6. 등급 · 사이징 · 코스피 동반

### 등급 (`phase`)
```
FEAR≥90 & ALL3      → STRONG (최강)
FEAR≥90 & n_on≥2    → BUY    (매수국면)
FEAR≥90             → ARMED  (장전·소액)
n_on≥2              → WATCH  (관찰)
그 외                → IDLE   (대기)
```

### 사이징 (신용 낙폭 depth)
```
creditDd ≤ −0.25 → 3차까지 ≈100%
creditDd ≤ −0.15 → 2차까지 ≈70%
creditDd ≤ −0.08 → 1차 ≈40%
그 외             → 소액 탐색 ≤20%
```

### 코스피 동반 (코스닥 카드 전용)
```
kospi_accompanies = (코스피 FEAR≥90) OR (코스피 ALL3) OR (코스피 creditDd ≤ −0.15)
코스닥 신호 점등(FEAR≥90 or ALL3) 시:
  동반이면  → SYSTEMIC   (양시장 공포 · 신뢰 높음)
  아니면    → KOSDAQ_ONLY (⚠️ 코스피 미동반 · 경고)
```

### ⚠️ 등급과 사이징은 **별개 두 축** (곱해서 씀)
- **등급** = *진입 여부·강도* — FEAR(공포)과 신호 충족 수로. GO/NO-GO + 확신.
- **사이징** = *분할 크기* — 신용 DD 깊이만으로. FEAR·ALL3와 무관(바닥 성숙도).
- **조합 규칙**: `IDLE·WATCH → 관망` · `ARMED → 소액 탐색` · `BUY·STRONG → 진입하고 DD 사다리(−8/−15/−25%=1/2/3차)만큼 분할`.
- 즉 "등급이 GO를 켜고, DD가 크기를 정한다." DD 사다리가 3차까지 차 있어도 등급이 IDLE이면 진입 대상이 아님.

## 7. 데이터 정합성 (`anchors.ts`) — 조용한 오류 차단

소스가 조용히 틀어지면(×8 배수 변경·TMPV 컬럼 이동·심볼 변경) 위 계산이 전부 무의미. **실측 앵커**로 2겹 방어.

### 앵커값 (직접 대조용)
| 지표 | 날짜 | 기준값 |
|---|---|---|
| 신용융자 유가 | 2026-07-07 | **29,074,973** 백만원 (= 29.075조) |
| 신용융자 코스닥 | 2026-07-07 | **7,990,423** 백만원 (= 7.990조) |
| 신용융자 전체(유가+코스닥) | 2026-06-24 | **38,632,824** 백만원 (= 38.633조) |
| 반대매매 비중 | 2026-07-07 / 06-24 | **2.2** / **7.5** (%) |
| 코스피 종가 | 2026-06-23 / 07-08 | **8203.84** / **7246.79** |
| 코스닥 종가 | 2026-07-08 / 07-07 | **785.00** / **831.23** |

### HARD assert (수집기 내부, 불일치 시 **throw → 소스 통째 거부** → 화면엔 '수집 실패'만, 이상값 X)
- `credit.ts`: 유가 07-07 + 코스닥 07-07 + **전체합 06-24**(`assertAnchorSum` — 한 컬럼만 스케일 틀어져도 잡음).
- `forcedLiq.ts`: 반대매매 07-07=2.2.
- `koreaIndexes.ts`: 코스피 06-23·07-08은 **hard**(둘 다 틀리면 지수 거부); 코스닥 07-08·07-07은 **soft-drop**(코스닥만 드롭, 코스피는 유지).

### 날짜 매칭 허용오차
- KOFIA: `tolMs=0` (정확 일치). 지수: `TZ_TOL_MS=20h` (tz 오프셋 ≤15h만 잡고 인접 거래일 ≥24h는 배제 → 앵커일 봉이 아직 없을 때 옆날 봉을 잘못 잡아 false-throw하는 사고 방지).

### SOFT 경고 (`checkAnchors` → `errors[]` → UI '일부 소스 수집 실패' 박스)
- 지수 staleness(지수 < KOFIA−2일 = TradingView 멈춤 의심).
- 앵커 전부 창 밖(2029년경 노후) → "검증 불가(새 앵커 필요)" 알림. ← **매년 새 앵커 1~2개 추가 권장**(그래야 hard assert가 계속 작동; 안 그러면 조용히 soft로 강등).

### 끊김 내성 (`carryForwardEmpty`)
- 이번 수집이 어떤 시리즈를 **빈 값**으로 받으면(TV WS 일시 끊김 등) 그 시리즈만 **직전 저장값 유지** → 한 소스 실패로 화면이 통째 비지 않음. 되돌림 시 "직전값 유지" 경고 + asOf staleness 배지로 오래됨을 표시. (근본 폴백 소스(pykrx 등)는 미구현 — 필요 시 추가.)

### KST 정렬 진단 로그
- `[koreaIndexes] 코스피 봉 raw=… UTC=… KST거래일=… 종가=…` — TV 봉 타임스탬프 규약을 눈으로 확인용. UTC날짜와 KST거래일이 다르면(전일 15:00Z 규약) `kstDay(+9h)`가 올바른 거래일로 정규화 중이란 뜻.

## 8. 직접 검증 체크리스트

1. **×8 보정**: Railway 로그 `[credit] 2026-07-07: 유가 29.075조 …` 확인. 유가 29.075 / 코스닥 7.990 / 전체 38.633이면 정상. (다른 날짜도 6일치 로깅됨 → 6/24 전체 38.633 대조)
2. **반대매매 컬럼**: 로그 `[forcedLiq] 반대매매 컬럼 = TMPV7 (앵커(07-07=2.2) 매칭)` 확인.
3. **지수**: 화면 코스피 종가가 KRX와 일치, 기준일 배지에 '지연' 없음.
4. **분위수/신호**: 화면 detail의 "상위 X%·하위 X%"가 값과 방향이 맞는지(반대매매=높을수록 공포, 이격도=낮을수록 공포).
5. **정합성**: 앵커가 틀어지면 그 소스가 '수집 실패'로 빠지고 이상값이 **안 뜨는지**(hard assert 작동).
6. **소스 대조**: 위 §7 앵커값 표를 KOFIA FreeSIS / KRX / Investing 실화면과 직접 대조.

> ⚠️ 이 지표는 소표본(n=6~16) 백테스트 기반의 **관찰 도구이며 투자 권유가 아니다.** 모든 판단과 결과는 사용자 책임.
